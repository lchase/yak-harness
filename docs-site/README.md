# docs-site

The [yak-harness](https://github.com/lchase/yak-harness) documentation
site — Docusaurus 3, deployed to
<https://lchase.github.io/yak-harness/> by
[`.github/workflows/docs-deploy.yml`](../.github/workflows/docs-deploy.yml)
on every push to `docs-site/**` on `main`.

Private workspace: its `package.json` is independent of the root
package, so the root's runtime-dependency rule (`zod` + `ajv` only) is
untouched.

## Local

```bash
cd docs-site
npm ci
npm start        # dev server with hot reload
npm run build    # production build to build/
npm run typecheck
```

Styling mirrors yak's docs site — `src/css/custom.css` is copied
verbatim (the quiet, restrained theme: neutral ink/paper, one indigo
accent, hairline borders, chevron sidebar marker).

The sidebar is autogenerated from the `docs/` folder structure; order
comes from `sidebar_position` frontmatter. The root path redirects to
the first doc (`src/pages/index.tsx`).

Content lives in [issue #29](https://github.com/lchase/yak-harness/issues/29);
this directory is the scaffold only.
